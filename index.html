🔐 QMS_APK_Signature

在安卓Termux中使用的APK签名与打包脚本

前往GitHub下载 查看更新日志

✨ 功能特性

🔏 自动签名与打包

移除旧签名，使用apksigner重新签名并验证，最后打包为ZIP文件。

🛡️ Argon2id + AES-256

支持高强度加密保存配置文件，保护你的Keystore密码和敏感信息。

🔄 自动备份与恢复

首次运行自动备份Keystore到随机目录，配置丢失时可快速恢复。

📋 完整性校验

输出证书SHA256、APK SHA256和ZIP SHA256，确保文件未被篡改。

🚀 快速开始

在 Termux 中执行以下命令：

pkg install openssl-tool argon2 zip openjdk-17
git clone https://github.com/QuantumMoveStudio-Open/QMS_APK_Signature.git
cd QMS_APK_Signature
chmod +x QMS-Signature.sh
./QMS-Signature.sh

首次运行按提示填写Keystore路径、别名和密码即可，后续自动读取配置。
